## 🚀 About This Project

A modern, world-class portfolio website built with **React** featuring an Apple-inspired **Liquid Glass UI** design. This portfolio showcases my skills, projects, and professional experience as a Full Stack Developer.

### ✨ Key Features

- 🎨 **Liquid Glass UI** - Glassmorphism effects with backdrop blur
- 🌗 **Dark/Light Mode** - System preference detection with toggle
- ⚡ **Framer Motion** - Smooth animations and transitions
- 📱 **Fully Responsive** - Mobile-first design for all screen sizes
- 🎬 **Interactive Demos** - Click-through project demonstrations
- 🔗 **SEO Optimized** - Meta tags and semantic HTML

## 🛠️ Tech Stack

### Frontend
- **React 18** - UI framework
- **Vite** - Build tool
- **Framer Motion** - Animations
- **React Router** - Navigation
- **CSS Modules** - Scoped styling
- **Lucide React** - Icons

### Backend & Tools
- **Python** & **Django** - Backend development
- **Git** & **GitHub** - Version control

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Hillary3000-web/my-portfolio-profile-.git

# Navigate to project
cd my-portfolio-profile-

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at `http://localhost:5173`

### Build for Production

```bash
npm run build
npm run preview
```
